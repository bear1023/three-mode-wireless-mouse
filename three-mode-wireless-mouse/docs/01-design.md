## 1. 作品概述

### 1.1 功能与特性

一款三模（有线 / 2.4G / 蓝牙）无线鼠标：

- **有线 USB 模式**：USB-C 连接，同时为电池充电；
- **私有 2.4G 模式**：配专属接收器（Dongle），面向低延迟电竞场景；
- **蓝牙 BLE 模式**：免接收器，连接笔记本/平板，低功耗。

传感器为原相 PAW3395（最高 26000 DPI）；电源为 800 mAh 锂电池 + TP4054 充电管理；固件基于沁恒 TMOS 调度，实现三模切换与低延迟上报。

### 1.2 应用场景

电竞/hardcore 游戏（需要低延迟、高回报率）、高端办公与创意设计（多设备切换）、移动办公（BLE 免接收器）。

### 1.3 技术特点

1. **单芯片三模**：CH585M 一颗芯片集成 USB / BLE 5.3 / 2.4G RF，省掉外挂蓝牙与 2.4G 芯片；
2. **私有 2.4G 协议**：固定 ID 配对、自动应答、跳频，目标高回报率；
3. **USB 协议栈深度定制**：自定义中断端点与报告描述符，缩短上报间隔；
4. **国产化 + 低成本**：单芯片方案压缩 BOM 与 PCB 面积。

## 2. 系统组成

![系统框图](images/system-block-diagram.png)

系统以 CH585M 为核心，分为四个部分：

| 子系统 | 组成 |
| --- | --- |
| 主控 | CH585M + 32 MHz 晶振 + 复位/BOOT 按键 + 下载电路 |
| 传感器 | PAW3395 + 透镜组，SPI 与主控相连，MOTION 引脚可做唤醒 |
| 电源 | USB-C 5 V → TP4054 充电 → 锂电池 → FS312F 保护 → 开关 → 662K LDO 3.3 V |
| 输入/接口 | 左右中微动、EC10E1220501 编码器、模式切换键、USB-C（数据 + 充电） |
| 接收器 | CH585M + π 型匹配 + 2.4G 陶瓷天线 + USB-A |

### 2.1 主控电路

![主控电路](images/schematic-mcu.png)

- X32M 外接 32 MHz 无源晶振（Y1）+ 2 × 22 pF 谐振电容；
- VDD33 / VSW / VDCID 等电源脚就近放置去耦电容（C20–C22 等）；
- 手动复位键 S2、BOOT 键 S3（进 ISP 烧录）。

### 2.2 供电与充电

- TP4054 线性充电：涓流 → 恒流 → 恒压三段式；
- FS312F-G 电池保护 IC + 双 MOS（Q1）：过充、过放、过流/短路保护；
- 保护后的 `V_BATT` 经拨动开关 SW1 作为总电源；
- 662K LDO 输出 3.3 V 供 MCU 与传感器。

### 2.3 接收器电路

![接收器电路](images/schematic-dongle.png)

- 与鼠标端同款 CH585M，保证射频与协议栈一致；
- RF 前端：π 型匹配网络（C5 / L1 / C4）+ 2.4G 陶瓷天线 ANT1；
- USB-A 直接插电脑取电并上报 HID；
- PB4 驱动状态指示灯 LED1。

## 3. 软件系统

![软件架构](images/software-architecture.png)

### 3.1 分层

| 层 | 职责 |
| --- | --- |
| 硬件驱动层 | GPIO（按键/编码器）、SPI（PAW3395）、USB 控制器、2.4G RF |
| 系统服务层 | TMOS 调度器、USB HID 协议栈、BLE GATT/GAP、2.4G 私有协议 |
| 应用逻辑层 | 输入处理、传感器读取、模式切换、报告分发 |

### 3.2 主应用与调度

`main()` 完成时钟（HSE + PLL → 62.4 MHz）、USB、RF 与外设初始化后进入 `TMOS_SystemProcess()` 主循环；应用逻辑集中在 `HidEmu_ProcessEvent()`，由周期性 `MOUSE_POLL_EVT` 事件驱动整条数据流。

### 3.3 模式切换与数据分发

- `check_mode_switch()`：检测 PB23 按键，`current_mode` 在 有线 / 蓝牙 / 2.4G 间循环；
- `apply_current_mode()`：按模式关闭 RF、开/关 BLE 广播、或初始化 2.4G；
- `hidEmuSendMouseReport()`：把同一份 HID 报告按当前模式发往 USB / BLE / 2.4G。

### 3.4 传感器驱动

封装在 PAW3395 相关函数中（`PAW3395_PowerUp`、`PAW3395_Write_Register`、`PAW3395_Motion_Burst`），向上只暴露"初始化"和"读一次运动数据"两个动作，屏蔽 SPI 细节与上百条寄存器配置。

## 4. 完成情况

### 4.1 机械

- 滚轮总成：橡胶圈滚轮 + EC10E1220501 编码器 + 独立中键微动，滚动与中键互不干扰；
- 传感器与透镜组固定在 PCB 预定位置，与底壳开孔严格对位，保证 LOD 与平面平行度。

### 4.2 电路

- 单芯片三模方案落地，PCB 尺寸与 BOM 成本优于多芯片方案；
- PAW3395 各电源轨独立去耦，模拟部分不受数字/射频干扰；
- 完整的充电 + 双重电池保护 + 稳压链路；
- 独立 2.4G 接收器硬件极简（MCU + 匹配网络 + 天线 + USB-A）。

### 4.3 软件

- 基于 TMOS 的事件驱动固件，多任务（传感器、三模通信、按键）并发；
- 三种模式无缝切换；
- 模块化解耦：驱动 / 服务 / 应用三层，便于替换传感器或协议栈。

## 5. 可扩展方向

1. 增加侧键与独立 DPI 键：PCB 预留按键位 + 扩展 HID 报告位 + 同步更新 2.4G 包结构；
2. RGB 灯效：滚轮/尾部加 WS2812B，用一个 GPIO 驱动，灯光与 DPI/电量联动；
3. 配套 PC 端配置软件：通过 USB 双向通信设置 DPI、LOD、回报率、宏按键。

## 画板注意事项（来自调试记录）

- 32 MHz 晶振走线尽量短，晶振与 MCU 之间不要走电源；
- PAW3395 的模拟电源与数字电源分开去耦，地平面完整；
- 2.4G 天线区域禁止铺铜、禁止走线，π 型匹配按实际板材调；
- USB-C 的 CC 引脚、ESD 器件不要省。
